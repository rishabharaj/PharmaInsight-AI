# Sources and credits

## Data and project code

The dataset is generated by this project's `generator.py`; no external dataset was copied. The source code was written for this project. The following GitHub starters were reviewed for practical ideas on a compact, filterable Streamlit sales dashboard:

- [mooceanstudio/streamlit-sales-dashboard](https://github.com/mooceanstudio/streamlit-sales-dashboard), MIT License, copyright © 2026 mooceanstudio. The clean separation between data, metrics, and presentation informed this project's small module structure. No code or dataset was copied.
- [shalininath123/Pharma_Dashboard_Analysis](https://github.com/shalininath123/Pharma_Dashboard_Analysis), consulted for pharmaceutical dashboard feature scope. Its dataset license was not established, so its dataset and code were not reused.
